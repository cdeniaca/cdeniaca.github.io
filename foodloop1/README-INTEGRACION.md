# Integración de FoodLoop en cristinadenicacarretero.com

Este paquete está preparado para el repositorio `cdeniaca/cdeniaca.github.io`, que es el que publica el dominio principal.

## Archivos que debes subir al repositorio principal

1. La carpeta completa `foodloop/` en la raíz del repositorio.
2. `images/FoodLoop_Logo.svg` dentro de la carpeta `images/` que ya existe.
3. Modificar el `index.html` principal para añadir FoodLoop en la sección Proyectos.

La URL final será:

    https://cristinadeniacarretero.com/foodloop/

## Cambio del index.html

Tu sección actual de Proyectos tiene Power BI, SQL y Visual Studio Code. Añade FoodLoop como cuarto elemento de la misma fila.

Puedes copiar el bloque de `CAMBIO-INDEX.txt` o sustituir toda la sección por `PROJECTS-SECTION-REPLACEMENT.html`.

## Repositorio Inventario

Puedes mantener `Inventario` como repositorio de desarrollo / histórico del código de FoodLoop. Para que la ruta final sea `/foodloop/`, la carpeta publicada debe estar también en el repositorio `cdeniaca.github.io`.

## Datos personales

No subas backups JSON, exportaciones Excel, tickets ni datos de inventario a GitHub. La carpeta `foodloop/` contiene solo código estático.
