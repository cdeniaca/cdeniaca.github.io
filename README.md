## Featured project: FoodLoop

FoodLoop is a local-first household inventory and purchase-tracking web application.

Key capabilities:

- IndexedDB persistence
- Purchase, consumption and stock history
- Replenishment suggestions based on observed habits
- Receipt OCR workflow in the browser
- CSV/XLSX exports
- Backup and restore
- Responsive mobile interface

➡️ **Demo:** https://www.cristinadeniacarretero.com/foodloop/

The portfolio is bilingual (Spanish / English) and deployed with GitHub Pages using a custom domain.
