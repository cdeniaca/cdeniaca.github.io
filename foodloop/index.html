PRIVACIDAD

Dónde están tus datos

FoodLoop no necesita cuenta, backend ni API. La base IndexedDB vive en el navegador de este dispositivo.

El código de la web puede estar publicado en GitHub; tus tickets e histórico no forman parte del repositorio.

Cuando utilizas el OCR, el navegador descarga Tesseract.js y su modelo de idioma, pero la foto del ticket se reconoce en tu dispositivo y no se guarda en FoodLoop.

Para no depender de una única copia local, usa periódicamente Mis datos → Descargar backup completo.
